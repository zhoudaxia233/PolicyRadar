# 政策雷达

[English](README.md) | 简体中文

追踪德国、法国、荷兰、瑞士、意大利、西班牙、英国、美国及欧盟的政策变化，提供官方来源及政策时间线。

这是一个静态网站，搜索与筛选在浏览器中运行，无需登录、数据库或应用服务器。

## 覆盖范围

- 欧盟：独立的超国家层级，历史解读涉及数字服务与市场、消费者权益、产品要求、支付和出行。已登记官方政策发现渠道，但完整监测及各国转化核查尚未完成。欧盟政策仅在欧盟视图中存储一份，不重复作为各国措施收录。
- 德国：联邦及全部 16 个州。
- 法国：全国及 18 个大区地理区域。
- 荷兰：全国及 12 个欧洲本土省份。
- 瑞士：联邦及全部 26 个州。
- 意大利：全国及全部 20 个大区；已完成初步来源登记及首篇全国层面解读。大区议会、大区公报和自治省尚未单独接入。

- 美国：联邦、全部50个州及华盛顿特区，已有首批官方记录和部分政策解读。覆盖仍不完整；州议会、州公报、地方及部落政府、海外领地尚未独立覆盖。
- 西班牙：全国、17个自治区及2个自治市；登记40个全国和地区政府／公报渠道，已补录2026年最低工资。历史扫描尚未完成，议会及其他地方机构未单独接入。
- 英国：全国及英格兰、苏格兰、威尔士、北爱尔兰；登记9个共享或权力下放机构的官方渠道，已开始补录历史法规目录及部分核实解读。逐项核对适用范围；地方政府、王室属地和海外领地未单独接入，历史扫描尚未完成。

覆盖尚不完整；网站会显示核查日期、扫描缺口及待核实线索。解读是编辑整理的摘要，不是官方法律文本。原始来源始终保留，并区分待决提案与已通过措施。

## 本地运行

使用 Node.js 24 LTS 和 npm。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:8080。修改源码或数据后需重新运行命令；该命令会构建并启动网站，不支持实时重载。

## 校验与发布

```sh
npm test
npx tsc --noEmit --incremental false
npm run build
```

推送到 `main` 后，[部署工作流](.github/workflows/pages.yml)会运行检查，并将 `dist/` 部署到 GitHub Pages。构建产物也可由其他静态托管服务提供。

## 数据维护

[data/current-export.json](data/current-export.json) 指定当前数据集。构建时会校验政策数据及归档原文的哈希值。归档原文不随网站发布；网站链接到 `main` 分支 `data/sources/` 中已提交的副本，因此新增的归档文件必须与使用它的导出一起推送。重新构建不等于重新核实事实；不得直接修改当前使用或历史导出文件的内容。

- [每周更新流程](data/UPDATE.md)：搜集、证据、新建导出及发布规则。
- [翻译维护](data/translations/README.md)：经核查的翻译及过期内容处理。
- [官方来源登记表](data/discovery-registry.json)：政策发现渠道及管辖范围。
